# Hotel Texas — Website

Initial responsive hotel landing page built with semantic HTML, CSS and vanilla JavaScript.

## Current experience
- Editorial luxury-hotel visual direction
- Responsive desktop and mobile navigation
- Hero, accommodation, dining and experiences sections
- Booking enquiry form UI with date validation
- Newsletter signup UI
- Accessible labels and image descriptions

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Important
The booking and newsletter forms are front-end placeholders. They do not create reservations or store email addresses yet. Connect a reservation provider and email service before accepting real guest details.
